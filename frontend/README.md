# Journey Junction — Frontend

Next.js 14 (App Router). Black / White / Yellow theme.

## Run

```bash
cd frontend
npm install
npm run dev   # http://localhost:3000
```

## Routes

- `/` — landing (link to all 3 role apps)
- `/customer` — mobile-first customer app (phone frame, home/search/detail/bookings)
- `/merchant` — merchant console (dashboard, fleet, bookings, promotions, earnings, KYC)
- `/admin` — admin console (overview, KYC approvals, payment verification, vehicles, users, merchants, finance)
